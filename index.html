How it works

The rules engine

A small TypeScript Go engine handles captures, suicide, ko and area scoring (komi 0.5 on 5×5). It's covered by unit tests and fast enough to play tens of thousands of games a second.

Monte Carlo tree search

For each candidate move, the agent plays thousands of quick random games and keeps the moves that win most often, balancing proven moves against unexplored ones. The heat map shows where those games went.

The value network

A small neural network (55 inputs, two hidden layers) trained on 15,000 positions judges games that run long, so the search spends its time on more positions instead of finishing every game.

How the agents compare

Over 10 games each: Monte Carlo beat alpha-beta search 10–0, and the final agent beat plain Monte Carlo 7–3. The search runs in a background thread, so the page stays smooth while it thinks.
